# Orthon Landing Project

Orthon Landing Project contains the production website, historical landing explorations, and design research assets for Orthon Capital Management.

## Repositories

- `orthon-landing` — current production landing site.
- `orthon-landing-archive` — frozen V1, V2, and V3 development history.
- `orthon-design-lab` — generated imagery, visual research, and asset experiments.

## Production

The current production implementation is V4, built with Astro and served as a static site with a small global settings API.

Production URL:

- https://orthon-v4.prin7r.com

## Handoff Principle

The organization separates production code from historical exploration. The active product remains compact and maintainable, while the archive and design lab preserve the complete creative and technical process.
